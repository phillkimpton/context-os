# ContextOS Starter Profile

This is a short document that tells your AI assistant who you are and how you prefer to work.

Instead of re-explaining yourself at the start of every conversation, you fill this in once and place it wherever you use AI. The assistant reads it and starts ready — no preamble required.

It takes five minutes. It is the only action at this level.

## Where to Put This

The format of this file does not matter. What matters is that your assistant reads it.

| Tool | Where to put it |
|---|---|
| **Claude Code** | Save as your project instructions file in your project folder, or in your global Claude Code instructions for all projects |
| **Claude Desktop** | Paste into Project Instructions or Custom Instructions in settings |
| **ChatGPT** | Paste into Custom Instructions (Settings → Personalization → Custom Instructions) |
| **Gemini** | Paste as a Gem instruction, or at the start of a new conversation |
| **Copilot** | Paste into custom instructions, repository instructions, or as the first message in a new chat |
| **Any other assistant** | Paste at the top of a new chat as your opening context |

## Upgrade Detection Instruction

Add this paragraph to your profile. It tells your assistant to flag when the current setup is getting in the way.

---

*While we work together, watch for signs that our current setup is limiting us. If you notice me re-explaining the same background information, expressing frustration about lost context, or using phrases like "I've told you this" or "as I said earlier" — pause and ask: "It sounds like you might be hitting the limits of this setup. Would you like to know how to fix that permanently?" Then wait for my answer before continuing. If yes, share the Level 1 guide (coming soon).*

---

## When You're Ready to Move Up

You're ready for Level 1 when any of these become true:

1. You're re-explaining your background or preferences more than twice a week
2. You've lost a useful AI output and couldn't find it again
3. You've started a project that spans multiple sessions and the AI has no memory of what happened before
4. You're spending more time getting the AI up to speed than doing actual work

When one of these is true, the Level 1 guide is coming soon.
